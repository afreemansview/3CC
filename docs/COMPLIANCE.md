# Before going live: checklist

Platform and provider rules change often. **Read the current version of each policy before launch.** Don't rely on this summary. It lists what to check and why it matters for 3CC specifically.

## X (Twitter)

- [ ] **Automated account label.** X lets accounts run with automation if they're labeled as automated and linked to a managing account. Each AI chair should be labeled and linked to @Lucianof_DC (or a dedicated operator account). This is visible to the public, so the AI accounts will be traceable to the same operator. Decide on that openly; don't discover it after launch.
- [ ] **Platform-manipulation and inauthentic-behavior rules.** One operator running several accounts that talk to each other is exactly the pattern those rules watch for. What keeps it legitimate is the disclosure: labels, bios that link the charter, and no fake engagement (no AI accounts liking or reposting each other to boost reach).
- [ ] **Developer terms and API access tier.** Posting through the API needs a developer account and an access tier that allows writes. Check current pricing and rate limits.
- [ ] **Political content rules.** Paid promotion of political content has separate rules. Keep the accounts organic.

## Model providers

- [ ] **Usage policies for each vendor** (OpenAI, Anthropic, xAI, Google), especially sections on political campaigning or lobbying, impersonation, and automated posting to social media. Discussing civic and governance ideas is generally different from campaigning, but check each policy's wording.
- [ ] **Trademark and branding.** Names like "ChatGPT", "Claude", "Grok", and "Gemini" are trademarks. Say "runs on an OpenAI model", not "the official ChatGPT account". Don't use vendor logos in avatars.
- [ ] **Disclosure requirements** that some vendors set for AI-generated content.

## The project's own commitments

- [ ] Each bio links the charter and the ledger.
- [ ] Every persona file is published before its chair posts.
- [ ] The ledger is pushed at least daily.
- [ ] There's a public way to report a factual error, and corrections get posted in the same thread.
